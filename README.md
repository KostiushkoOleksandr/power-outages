# Графік відключень світла

Застосунок показує графіки відключень електроенергії для областей України:
поточний статус, час до наступної зміни та розклад на день. Працює офлайн.

**Демо:** https://kostiushkooleksandr.github.io/power-outages/

## Можливості
- Вибір області та черги, вибір запамʼятовується
- Поточний статус і зворотний відлік до наступного відключення
- Офлайн-режим (Service Worker + локальний кеш даних)
- Світла, темна та системна теми
- Попередження, якщо дані застарілі або немає звʼязку з джерелом
- Адаптивний інтерфейс для телефона, встановлення як PWA

## Технології
React, TypeScript, Vite, vite-plugin-pwa, GitHub Actions + GitHub Pages

## Дані
Дані беруться з відкритого неофіційного репозиторію
[yaroslav2901/OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA)
і можуть містити неточності.
